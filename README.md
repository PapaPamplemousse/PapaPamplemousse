## Flagship Project: LibreOrbit

[**LibreOrbit**](https://github.com/LibreOrbit) is an open-source project focused on the development of reusable flight software components for aerospace applications. The project aims to provide implementations of commonly used software functions and standards for students, research institutions, and aerospace developers.

- [**OrbitC**](https://github.com/LibreOrbit/OrbitC) (C) — A C library for embedded aerospace software. It builds upon concepts and implementations from my previous project, [**ChaosLib**](https://github.com/PapaPamplemousse/ChaosLib), with a focus on memory management, deterministic execution, and resource-constrained targets.
- **Upcoming Modules** — Development of additional software components, including a planned implementation of the Packet Utilization Standard (PUS) for satellite telemetry and telecommand management.
