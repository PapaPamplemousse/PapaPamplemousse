## Selected Projects ( English Version )

* [**ChaosLib**](https://github.com/PapaPamplemousse/ChaosLib) (C) — A modular, alternative standard C library (libc) tailored for critical embedded systems. Configurable and optimized for resource-constrained microcontrollers, it prioritizes memory safety, predictable string handling, and mathematical determinism by design.
* [**Haunted_Village_Tycoon**](https://github.com/PapaPamplemousse/Haunted_Village_Tycoon) (C++) — A real-time, autonomous simulation and village management engine. It implements complex systems and state machine mechanics to orchestrate independent behavioral AI for simulated entities.
* [**SmartCVBuilder**](https://github.com/PapaPamplemousse/SmartCVBuilder) (Python) — A documentation pipeline automation tool designed to generate professional PDF resumes parsed from structured YAML configuration files.
* [**JdrGatchaLoot**](https://github.com/PapaPamplemousse/JdrGatchaLoot) (Python) — A random loot generation utility for tabletop RPGs. Features a weighted-rarity distribution algorithm (gacha mechanics) designed to assist game masters in reward balancing and session pacing.

## Projets Sélectionnés ( Version Française )

* [**ChaosLib**](https://github.com/PapaPamplemousse/ChaosLib) (C) — Bibliothèque standard (libc) alternative et modulaire dédiée aux systèmes embarqués critiques. Conçue pour être configurable et adaptable aux microcontrôleurs à faibles ressources, elle met l'accent sur la sécurité mémoire, la gestion prévisible des chaînes de caractères et le déterminisme mathématique.
* [**Haunted_Village_Tycoon**](https://github.com/PapaPamplemousse/Haunted_Village_Tycoon) (C++) — Moteur de simulation autonome et de gestion de village en temps réel. Implémente des mécaniques de systèmes complexes et d'automates pour orchestrer le comportement indépendant des entités de la simulation.
* [**SmartCVBuilder**](https://github.com/PapaPamplemousse/SmartCVBuilder) (Python) — Outil d'automatisation de pipeline documentaire permettant de générer des CV au format PDF à partir de fichiers de configuration structurés en YAML.
* [**JdrGatchaLoot**](https://github.com/PapaPamplemousse/JdrGatchaLoot) (Python) — Script de génération de butin aléatoire pour jeux de rôle sur table. Intègre un algorithme de distribution basé sur un système de rareté pondérée (mécanique de gacha) pour assister le maître de jeu dans l'équilibrage des récompenses.
